# AI governance decision records

Create a numbered Markdown file for durable decisions that affect AI governance, protected surfaces, architecture, or cross-tool behavior.

Use this template:

```markdown
# NNNN: Decision title

- Status: proposed | approved | superseded
- Date: YYYY-MM-DD
- Owner: Project owner (ABADO)
- Approval evidence: issue, task, or review reference

## Context

## Decision

## Alternatives considered

## Consequences

## Verification and rollback
```

Do not include secrets, credentials, personal data, or sensitive production details.
