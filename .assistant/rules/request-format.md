# Recommended task request format

For substantial work, provide or derive these seven fields:

1. **Objective** — the outcome to achieve.
2. **Context** — relevant users, business rules, and current behavior.
3. **Scope** — included applications, packages, files, and environments.
4. **Non-goals** — behavior that must remain unchanged.
5. **Acceptance criteria** — observable success and failure cases.
6. **Verification** — expected tests, checks, and evidence.
7. **Approvals and constraints** — protected surfaces, authorized actions, deadlines, and operational limits.

Missing fields are not permission to broaden the task. Infer only low-risk details from repository evidence; ask Project owner (ABADO) when a choice materially changes behavior, data, money, production, security, or AI configuration.
